# LabMate 實驗室開發助手

一個完全在本機執行、零付費 API、供實驗室長期使用的開發工具助手。它會搜尋 `knowledge/` 內的 Markdown 文件，再請本機 Ollama 根據找到的內容回答，並顯示來源。

## 功能

- 實驗室文件問答與來源標示
- 找不到資料時明確回覆不知道
- 開發能力清單（進度保存在使用者瀏覽器）
- 自動列出本機已安裝的 Ollama 模型
- 不依賴任何第三方 Python 套件

## 安裝與啟動

1. 安裝 [Ollama](https://ollama.com/download)。
2. 開啟終端機，下載一個支援中文的模型：

   ```powershell
   ollama pull qwen3:1.7b
   ```

3. 在本專案目錄啟動：

   ```powershell
   python app.py
   ```

4. 瀏覽器開啟 <http://127.0.0.1:8000>。

若模型名稱不同，可以在頁面右上角選擇，或設定 `OLLAMA_MODEL` 環境變數。

## 更新實驗室資料

直接新增或修改 `knowledge/*.md`。每個 `#`、`##` 或 `###` 標題會被視為一個可檢索段落，不需要重新建立索引或重新啟動。

可持續補充實驗室常見的開發文件，包括：

- VS Code 與終端機設定
- Git 工作流程
- Python 與虛擬環境
- 套件版本與環境問題
- 常見錯誤及處理方式

不要把真實密碼、私鑰或 API 金鑰寫入知識文件。

## 測試

```powershell
python -m unittest discover -s tests -v
```

## 區域網路使用（選用）

預設只允許本機連線。如果要讓同一個實驗室網路中的其他人使用，可將 `LABMATE_HOST` 設成 `0.0.0.0` 後啟動。開放前應先加入登入驗證、防火牆規則與管理員核准；目前 MVP 不適合直接公開到網際網路。
