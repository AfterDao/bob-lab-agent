# 開發工具

## 必要工具

常用工具包含 VS Code、Git 和 Python。安裝完成後，請在終端機確認 `git --version` 與 `python --version` 能正常顯示版本。

## VS Code

先學會開啟專案資料夾、使用整合終端機、搜尋檔案、安裝專案需要的擴充套件，以及選擇正確的 Python interpreter。不要在不知道作用的情況下大量安裝擴充套件。

## Git 基礎

第一階段需要理解 repository、commit、branch 的概念，並能完成 clone、status、add、commit、pull 與 push。修改共同專案前，先建立自己的分支，不要直接修改主要分支。

## Python 環境

每個專案使用獨立的虛擬環境，並依照專案 README 安裝套件。不要把大型資料集、密碼、API 金鑰或虛擬環境資料夾提交到 Git。

## 錯誤排查

排查前先記錄作業系統、Python 版本、套件版本、執行指令與完整錯誤訊息。從錯誤訊息最後一段開始閱讀，確認檔案路徑、行號和錯誤類型，再一次只改一項設定並重新測試。
