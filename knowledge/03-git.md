# Git 使用指南

## 日常操作

開始工作前先執行 `git status` 確認狀態，再使用 `git pull` 更新分支。完成一個明確的小改動後，使用 `git add` 和 `git commit` 保存。提交訊息應說明做了什麼，不要只寫 update 或 fix。

## 分支

新功能與修正應在獨立分支進行。切換分支前先確認目前修改是否已提交或妥善保存。合併前檢查差異並執行測試，不要在不理解影響時強制覆蓋遠端歷史。

## 不應提交的內容

密碼、API 金鑰、私鑰、大型資料集、模型權重、虛擬環境與暫存檔不應提交。請使用 `.gitignore` 排除，已洩漏的金鑰必須立即撤銷，不能只從 Git 中刪除。
